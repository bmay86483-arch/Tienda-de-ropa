TIENDA DE ROPA

Descripción

Sistema de gestión para una tienda de ropa desarrollado en Java.

Tipos de usuarios

* Visitantes: cuentan con un ID propio.
* Trabajadores: cuentan con un ID propio.
* Proveedores: cuentan con un ID propio.

Funciones

* Registrar visitantes.
* Registrar trabajadores.
* Registrar proveedores.
* Generar identificadores automáticamente.
* Consultar los registros.

Lenguaje de programación

Java.
